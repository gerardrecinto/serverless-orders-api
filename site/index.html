serverless-orders-api

An orders API on AWS in Node.js and TypeScript. API Gateway and Lambda take the request, DynamoDB stores it, SQS hands it to a worker, and Terraform builds all of it.

Source on GitHub · run it locally with npm install && npm run dev

What is in the repo


    

  • TypeScript handlers with injected dependencies; 21 tests (94% line coverage) including redelivery, conflicts and partial batch failure; handler p99 0.071 ms in-process.
    • 

  • Terraform modules for data, functions, API and alarms. IAM is least privilege per function and a test fails on any wildcard action.
    • 

  • Alarms for 5xx, p99 latency, function errors, a non-empty dead-letter queue and queue age.
    • 

  • CI runs type check, tests, build, terraform fmt and validate, and a Trivy scan. Deploy uses GitHub OIDC, no stored keys.
